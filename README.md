# ComfyUI 全景解析

一个零依赖的中文可视化知识库，帮助对 AIGC 有兴趣但不熟悉底层原理的读者系统理解 ComfyUI：

- **第一部分 · 架构解析** — 前后端架构、执行引擎（增量缓存 / 拓扑排序 / 显存调度）、源码目录导读、自定义节点开发、接管 ComfyUI 的三条路线（含可运行的 API 客户端示例）
- **第二部分 · 节点包全解** — 官方核心节点 + 主流第三方节点包，逐节点分析：功能 / 真实结构可视化 / 上下游 / 参数选项含义 / 为什么需要。节点卡片左侧是与 ComfyUI 同构的可交互节点图，点击端口或控件右侧详情自动展开
- **第三部分 · 工作流图鉴** — 每条工作流提供：可交互节点图（点击看职责、高亮数据链路、按阶段聚焦），图下方是「数据流讲解 / 管线阶段拆解 / 逐节点分析」三合一联动面板（tab 切换、可收起，各 tab 带上一步/下一步/重置步进与顶部当前选中卡，与图双向联动）；另有依赖清单（类型徽章 + 获取指引）、可展开的源 JSON 与一键下载
- **第四部分 · 真实工作流库** — 从 Civitai 公开抓取并解析的真实社区工作流（~2332 条 + ~3055 份交互节点图）：多维表格视图支持按作者 / 类别 / 底模等任意列筛选、排序与分组聚合；详情页含节点构成、需装节点包、模型依赖与 AI 深度讲解（渐进覆盖中，含管线阶段拆解与图内高亮联动）；另有**专题层**，把模型家族 / 一类玩法（如视频生成、MiniMax-H3）单独拎出来做对比表、子主题分组与规格速查

## 工作流源文件的来源

工作流页面的源文件分两类，页面上有明确徽章标注：

- **📄 真实文件**：从公开仓库下载的原始工作流（ComfyUI 官方模板库 [Comfy-Org/workflow_templates](https://github.com/Comfy-Org/workflow_templates)、[cubiq/ComfyUI_Workflows](https://github.com/cubiq/ComfyUI_Workflows) 等），可点击溯源，25 个，全部通过 `scripts/validate-workflows.mjs` 结构校验
- **🧪 本站自制参考版**：暂无公开原始文件对应的工作流（如换脸、NSFW 结构解析），依据社区通用结构构造的 API 格式参考实现，同样经过结构校验

## 特性

- 🎨 **三套主题**，顶栏右侧一键切换、选择自动记住：**精装出版物**（默认，米白纸底 + 衬线 + 书籍流）、**数据人文主义**（深靛 Riso + 章节带 + 手写体批注）、**原版深色**（仿 ComfyUI 暖色节点风）。节点图画布始终保持 ComfyUI 原生渲染，只有外框随主题
- 🖱 全部节点图可交互：拖拽平移、滚轮缩放、点击节点弹出说明并高亮上下游
- 🔗 工作流节点可一键跳转到第二部分对应节点包详解
- 🔍 全站搜索（Ctrl+K）、分类筛选、阶段聚焦、上一条/下一条导航
- 📦 零外部依赖（无 CDN、无框架、无构建步骤，字体也已本地化），国内网络可直接访问

## 本地运行

直接双击 `index.html`，或用 node 开发服务器：

```bash
node _sources/dev_server.cjs
# 打开 http://127.0.0.1:8090
```

> 注：本机无 Python，`python -m http.server` 不可用；node 方式同时支持 hash 路由与静态资源。

## 校验与数据质量

```bash
node scripts/validate-workflows.mjs assets/files/workflows
```

校验项：JSON 可解析、UI 格式（含子图）/API 格式结构完整、连线引用的节点与槽位存在、class_type 非空。

## 数据来源与声明

内容基于 ComfyUI v0.34.2 源码结构与各节点包官方文档整理。本站不托管任何模型文件、不提供下载渠道；涉及换脸与人像内容均附合规提示；「成人内容」部分仅为管线结构的技术解析（18+，遵守当地法律）。

第四部分工作流数据来自 Civitai 公开 API（关键词 workflow、类型 Workflows），仅收录元数据与工作流 JSON 结构用于技术解析，按平台规则下载均经账号鉴权；NSFW 标记内容默认隐藏（页面有开关）。抓取数据中发现的第三方泄漏凭据（如内嵌的 Hugging Face token）已在发布前统一打码。

## 更新方式

在本地修改后推到 main 分支：GitHub Pages 自动重新发布，Cloudflare Pages 由工作区的 `_sources` 脚本手动部署。站点零外部网络依赖，字体与图片均已本地化，因此每次发布都要带上 `assets/fonts/`。项目约定见 [AGENTS.md](AGENTS.md)。
